# 🧮 Dynamic Discount Calculator (Java)

A simple Java calculator application that computes dynamic discounts on a given price — useful for practicing conditional logic and pricing calculations.

## 🛠️ Tech Stack
- Java (Core Java)
- IntelliJ IDEA project structure

## ✨ Features
> Update this list with your actual implemented features, for example:
- Enter product price and quantity
- Calculate discount based on price range / quantity slabs
- Display final payable amount after discount
- Handle multiple discount rules (e.g. seasonal, bulk-purchase)

## 🚀 How to Run
1. Clone the repository:
   ```
   git clone https://github.com/Sandip678/DynamicDiscountCalculator.git
   ```
2. Open the project in IntelliJ IDEA / Eclipse.
3. Locate the file inside `src/` containing the `main()` method.
4. Run it directly from the IDE.
